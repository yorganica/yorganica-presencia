# Yorgánica Presencia — v3.2 piloto para GitHub Pages

## Instalar desde cero
1. Descomprime el ZIP en Windows: clic derecho > Extraer todo.
2. En github.com crea un repositorio **público** llamado `yorganica-presencia`.
3. En el repositorio selecciona Add file > Upload files. Arrastra los **11 archivos del interior**, NO el ZIP ni la carpeta que los contiene.
4. Pulsa Commit changes.
5. En Settings > Pages > Build and deployment: Deploy from a branch > main > /(root) > Save.
6. Espera unos minutos y visita `https://TU-USUARIO.github.io/yorganica-presencia/`.
7. En iPhone: Safari > Compartir > Agregar a pantalla de inicio. En Android: Chrome > menú > Instalar app / Agregar a pantalla principal.

## Funciones y límites
- Temporizador definido de 1 a 1440 minutos, y modo libre sin fin programado.
- Diario editable, estadísticas, exportación CSV, JSON y PDF mediante impresión.
- Ocho idiomas para los textos principales; hay traducciones secundarias pendientes.
- Datos locales: haz respaldos JSON; no hay sincronización entre dispositivos.
- Funciona sin conexión tras primera carga exitosa.
- Accesos rápidos de 5, 10, 20 minutos y tiempo libre en plataformas que admiten shortcuts PWA. **No son widgets nativos.**
- Versión piloto no probada en todos los móviles. El sonido con pantalla bloqueada no está garantizado.

Cuatro sonidos opcionales: campana original, cuenco tibetano, gong y campanillas. Son recreaciones electrónicas originales generadas por el navegador, no grabaciones acústicas. Pulsa **Escuchar** para probarlos. El sonido con la pantalla bloqueada puede variar según el dispositivo.
